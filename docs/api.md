# API reference

Interactive documentation is generated by FastAPI at `/docs` (Swagger UI) and `/redoc` when the server runs.

All routes except `/api/health` and `/api/auth/token` require `Authorization: Bearer <token>`.

## Authentication

| Method | Path | Description |
|---|---|---|
| POST | `/api/auth/token` | OAuth2 password form (`username` is the e-mail). Returns `access_token` and the user. |
| GET | `/api/auth/me` | Current user |

```bash
TOKEN=$(curl -s -X POST localhost:8000/api/auth/token \
  -d "username=you@example.com&password=..." | python -c "import sys,json;print(json.load(sys.stdin)['access_token'])")
```

## Analyses

| Method | Path | Description |
|---|---|---|
| POST | `/api/analyses` | Upload a PDF (`multipart`, field `fichier`, 20 MB max). Returns a job id. |
| GET | `/api/analyses/jobs/{job_id}` | Job progress (steps 1 to 5) and final analysis id |
| GET | `/api/analyses` | History, most recent first |
| GET | `/api/analyses/{id}` | Full detail: documents, comparison, revisions |
| PATCH | `/api/analyses/{id}/revisions` | Apply operator revisions and replay L6 to L8 |
| GET | `/api/analyses/{id}/rapport` | Download the PDF report |
| GET | `/api/stats` | Dashboard figures |
| GET | `/api/health` | Liveness probe, no authentication |

Upload errors: `422` for a non-PDF content type or a file that does not start with `%PDF-`, `413` above the size limit.

## Revision format

The `PATCH` body is the complete state of revisions for the analysis (not a delta). It is stored as an audit trail.

```json
{
  "corrections": {
    "BL": { "3": { "quantite": "60" } }
  },
  "rapprochements": {
    "BC↔BL": { "affectations": { "0": [2, 4] }, "detachees": [5] },
    "BC↔Facture": { "affectations": { "1": [0] } }
  }
}
```

- `corrections`: by document type, then by original line index, with fields written as raw strings. Normalization and validation run again afterwards. Correctable fields are `reference`, `designation`, `unite`, `quantite`, `prixUnitaireHT`, `tauxRemise` and `montantHT`; an unknown field, a negative amount, a non-numeric value or a discount above 100 returns `422`.
- `rapprochements`: line assignments. `affectations` maps a BC line index to the target document line indices. `detachees` lists target lines to leave unmatched. Indices are original line positions, never internal ones.

The same `rapprochements` structure is accepted by `concordance revise <folder> file.json` (flat form, without the `corrections` wrapper):

```json
{ "BC↔BL": { "detachees": [0] } }
```

Run `concordance revise <folder>` without a file to print every line with its index and the pending ambiguities.
